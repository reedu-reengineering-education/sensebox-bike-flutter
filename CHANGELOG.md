# Changelog

What's new for senseBox:bike riders, version by version.

## 3.5.0

- 🎨 Big UI redesign: recording settings like upload mode and recording mode now live in the senseBox selection button, right where you pick your box.
- 🚲 New tablet-friendly layout for bigger screens.
- ⏱️ Periodic and on-tap data collection modes, alongside the classic GPS-driven mode.
- ✨ Remember a senseBox — it'll auto-connect the moment it's powered on and in range. Turn it on from the menu next to a device in the connection sheet.
- ℹ️ App version now shown on the Settings page — tap it any time to see this changelog again.
- ⚡ Tracks load faster: we cache ride summaries instead of rescanning your whole GPS history every time.
- 🛠️ Fixed compatibility with newer senseBox configurations.

## 3.4.0

- 🌐 Pick from a list of ready-made openSenseMap API URLs in Settings.
- 🔗 Bluetooth connecting and reconnecting got a lot more reliable.
- 📍 iOS now asks for "Always" location access up front, so background tracking keeps working.
- 🔋 Bluetooth no longer drops when your phone's battery saver kicks in.
- 📄 GPS speed is preserved correctly when exporting CSVs from the classic box.
- 🔴 The track overview now shows a red icon if a direct upload failed.
- 🔑 Fixed a hiccup when navigating to sign in.

## 3.3.9

- 🇫🇷 French localization.
- 🔐 A link to reset your password, right from the login screen.
- ✅ Only senseBox:bike compatible boxes show up after logging in.
- 🐛 Fixed how acceleration sensor data was prepared.

## 3.3.5

- 📦 Support for a new senseBox model.
